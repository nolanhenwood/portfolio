Mini Cooper glove box hinge

Project overview

When the hinge on my Mini Cooper glove box needed replacing, I found that I could not buy the hinge separately and there was no existing 3D model online. I designed and printed a replacement and used it in the car.

Project notes

This project let me use 3D printing to solve a specific repair problem with a custom part.
